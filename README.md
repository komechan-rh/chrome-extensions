# chrome-extension

Chrome 拡張をまとめて管理するリポジトリです。拡張ごとにディレクトリを分け、それぞれ独立した npm プロジェクトとして扱います。

| ディレクトリ | 概要 |
| --- | --- |
| [`github-viewed-sync/`](./github-viewed-sync) | GitHub の PR「Files changed」で `Viewed` にしたファイルを、左サイドバーのファイルツリーへ視覚的に反映する拡張 |

各拡張のセットアップ・ビルド・Chrome への読み込み手順は、それぞれのディレクトリの README を参照してください。
